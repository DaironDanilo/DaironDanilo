### 🌐 GLTF Viewer with Filament
> A lightweight Android-based 3D model viewer built using [Google's Filament](https://google.github.io/filament/), capable of rendering `.glTF` and `.glb` files.

- Built with **Jetpack Compose + Android Views**
- Powered by **Filament** for physically-based rendering (PBR)
- Supports loading and displaying local `.glb`/`.gltf` assets
- Ideal for 3D model previews in Android apps

[🔗 View repo](https://github.com/DaironDanilo/filamentDanilo)
